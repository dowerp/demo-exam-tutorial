# Настройка BR-FW

## Настройка имени
Через браузер на BR-CLI заходим 10.20.30.1:8080
Заходим открываем сендвич-меню и там переходим в консоль
```bash
hostnamectl set-hostname br-fw.au-team.irpo
exec bash
```
