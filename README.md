# Подготовка к демонстрационному экзамену (ДЭ 2026)

Практическое руководство и шпаргалка по настройке сетевой инфраструктуры, серверов и сервисов для сдачи демонстрационного экзамена по компетенции **«Сетевое и системное администрирование»**.

### Для любителей скорости только команды [Модуль 1 по-быстрому](Module-1(fast).md) и [Модуль 2 по-быстрому](Module-2(fast).mod)

## О репозитории

В репозитории собраны готовые команды и разборы конфигурационных файлов, разбитые по модулям и конкретным машинам топологии. Материал структурирован так, чтобы во время подготовки и выполнения заданий не тратить время на поиск синтаксиса и отладку типовых ошибок.

> **Важно:** Все IP-адреса, имена доменов и пароли приведены на основе типового задания 2026 года. На реальном экзамене обязательно сверяйте параметры адресации со своей схемой и заданием!

## Структура материалов

### [Модуль 1: Сетевая инфраструктура и базовые сервисы](Module-1(main).md)
* **ISP:** трансляция адресов (NAT / Masquerade), маршрутизация в ядре Linux.
* **HQ-RTR / BR-RTR (EcoRouter):** настройка GRE-туннеля между офисами, динамическая маршрутизация OSPF с MD5-аутентификацией, NAT/PAT, синхронизация времени NTP.
* **HQ-SW (Open vSwitch):** настройка транков, access-портов и VLAN (100, 200, 999).
* **HQ-SRV / BR-SRV (ALT Linux):** статическая адресация через `etcnet`, правила `sudoers`, баннер SSH, авторитетный DNS-сервер BIND (прямая и обратная зоны).
* **BR-FW (Ideco NGFW):** подключение и OSPF-маршрутизация через веб-интерфейс.

### [Модуль 2: Централизованная аутентификация и сервисы](Module-2(main).md)
* **BR-SRV:** контроллер домена Active Directory на базе Samba DC (создание пользователей и групп скриптом), инвентарь хостов Ansible.
* **HQ-SRV:** веб-приложение Apache HTTPD + PHP, СУБД MariaDB, развертывание схемы из дампа и права доступа.
* **ISP:** обратный прокси Nginx (Reverse Proxy) и HTTP Basic Authentication (`htpasswd`).
* **HQ-CLI / BR-CLI:** синхронизация времени Chrony, ввод рабочей станции в домен через Alterator, ролевые ограничения `sudo` для доменных групп, автомонтирование сетевых ресурсов NFS.

## Формат файлов

Для каждого модуля подготовлено два вида файлов:
1. `*_commands.md` — чистые списки команд по машинам для быстрой вставки без лишнего текста.
2. `*_explained.md` — подробные разборы с готовым содержимым конфигурационных файлов и пояснениями директив.
